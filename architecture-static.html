System overview

GitHub hosts the static frontend; all application data and processing cross the HTTPS SmartRPD API boundary.

UserGitHubGCP APIProcessingDatabaseAssurance

Trust boundaries

Public static tierGitHub Pages delivers HTML, CSS, JavaScript and dental assets. It must contain no trusted secrets.
Public API boundaryThe browser calls only the HTTPS SmartRPD API. Authentication, authorization, validation, throttling and filtering belong here.
Protected GCP tierProcessing and database services are reachable through controlled API workloads—not directly from the frontend.

GitHub Pages frontend delivery

Purpose: deliver the SmartRPD browser interface and route user actions to the GCP API.

Flow steps

1. Open SmartRPDGET https://ndcs-smartrpd.github.io/tmp.rpd/
2. Deliver static UIGitHub returns frontend files; no GCP database data is hosted on Pages.
3. Run workflows locallyThe browser renders dashboards, case management, 2D annotation and 3D viewing.
4. Cross the API boundaryhttps://live.api.smartrpdai.com/api/smartrpd

Important finding

src/js/shared/config.js contains browser-visible credential-like values and warns they are readable in DevTools. They are not secrets or a security boundary. Rotate any live credential, remove privileged/static credentials from the frontend, and enforce identity and authorization on the server.
